# Vocab

原生 macOS 查词与主动英语表达练习工具。Apple Silicon / macOS 14+。

- 本机 Oxford 词典：紧凑查词、英英/中文、词性与搭配，支持选区及局部 OCR。
- 学习空间：主动表达、语音转写、AI 反馈和综合交流。
- 知识地图：可独立更新的正式知识目录；个人进度、回答及收藏留在各自电脑。

[安装、配置与升级](docs/INSTALL.md) · [知识维护与发布](docs/MAINTAIN.md) · [正式知识版本](knowledge/latest.json)

首发 112 个知识点、314 个情境。目录含原创教学内容及可追溯来源索引；不包含参考书原始文件、Oxford 词库或个人学习数据。

AI 功能使用你本机 Pi 中自己的账号；只有主动调用时相应问题、词典解释、阅读语境或练习答案会被发送给你配置的供应商。查词、学习数据库和知识目录不需要 AI。可选连接自己的 Codex 聊天和本机语音服务。

源码可查看、个人非商业使用；非传统开源项目。软件见 [LICENSE](LICENSE)，教学知识见 [knowledge/LICENSE.md](knowledge/LICENSE.md)。商业使用或对外分发改编版本须另行取得许可。
